Claude Code 전역 개발설정 (범용 · 어느 프로젝트에서나)
==========================================================

이 폴더는 "내 컴퓨터의 Claude Code 전역 설정"을 한 번에 적용하는 설치 도구입니다.
특정 프로젝트(GIS 등) 전용 규칙은 들어 있지 않습니다.


쓰는 방법 (딱 세 단계)
----------------------
1. ZIP 파일을 마우스 오른쪽 → "모두 압축 풀기".  (풀지 않고 열면 동작하지 않습니다)
2. 풀린 폴더 안의 INSTALL-GLOBAL.bat 을 더블클릭.
   - "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행" 을 누르세요.
   - 검은 창이 뜨고, 끝나면 "완료했습니다"가 나옵니다. 아무 키나 누르면 닫힙니다.
3. Claude Code 를 완전히 종료했다가 다시 실행.

확인: Claude Code 에서 /status 를 입력했을 때 모델이 Opus 5.5 이면 적용된 것입니다.

먼저 무엇이 바뀔지만 보고 싶으면 CHECK-ONLY.bat 을 더블클릭하세요(아무것도 바꾸지 않습니다).

필요한 것: Node.js 18 이상. 없으면 검은 창이 설치할지 묻습니다(Y 를 누르면 winget 으로 설치).
이미 있으면 아무것도 묻지 않고 바로 적용합니다.


무엇이 바뀌나 (내 컴퓨터의 사용자 폴더 C:\Users\내이름\.claude 안만 바뀝니다)
--------------------------------------------------------------------------
- settings.json  (없으면 새로 만들고, 있으면 "없는 항목만 추가"합니다)
    모델 claude-opus-5-5, 노력 수준 high, 답변 언어 한국어, 대화 기록 90일 보관
    명령 대기 시간: 기본 10분 / 최대 30분
    Windows 에서는 PowerShell 도구를 켭니다(CLAUDE_CODE_USE_POWERSHELL_TOOL=1)
    안전: "권한 검사 우회 모드"를 끕니다
    허용(물어보지 않고 실행): cmake --build/--preset/-S/-B, ctest --preset/--test-dir,
      clang-format, clang-tidy, 그리고 C++ 문서 사이트(cppreference, cmake.org, clangd, code.claude.com) 읽기
    차단: .env 파일 읽기·수정, git push --force, git reset --hard
    안전 점검 훅 1개, 화면 아래 상태 줄
- hooks 폴더        안전 점검(guard.mjs)과 상태 줄(statusline.mjs)
- CLAUDE.md         전역 C++ 개발 지침 (표시가 있는 "관리 블록"만 갱신하고 내가 쓴 글은 그대로 둡니다)
- skills 폴더       /개발설정 명령(어느 프로젝트에서나 사용)

안전 점검 훅이 하는 일: 되돌릴 수 없는 명령(강제 푸시, 통째 삭제, git add -A, 다운로드 즉시 실행 등)을
실행 직전에 막거나 사용자에게 다시 묻습니다. 문서·커밋 메시지 안의 글자는 막지 않습니다.


이미 내 설정이 있으면
--------------------
- 내가 정한 값(예: 다른 model)은 그대로 두고, "내 값을 유지함"이라고 알려 줍니다.
  권장값으로 바꾸고 싶을 때만 Claude Code 에서 "/개발설정 전역 강제" 를 실행하세요.
- 허용/차단 목록은 "합집합"입니다. 내가 일부러 지운 항목이 다시 실행하면 되돌아올 수 있습니다.
- 바꾸는 파일은 항상 백업(파일이름.bak-날짜-시각)을 먼저 만듭니다.
- settings.json 에 주석(//)이나 쉼표 오류가 있으면 아무것도 바꾸지 않고 멈춥니다(내 글을 지우지 않기 위해).
- CLAUDE.md 의 관리 블록 표시가 망가져 있으면 그 파일은 건드리지 않고 알려 줍니다.


되돌리는 방법
-------------
바꾼 파일 옆에 생긴 .bak-날짜 파일의 이름에서 .bak-… 부분을 지우면 원래 상태입니다.
(새로 만든 파일은 그냥 삭제하면 됩니다.)


여러 번 눌러도 되나요?
--------------------
네. 같은 결과가 되며, 바뀔 것이 없으면 "이미 최신"이라고만 나옵니다.


새 C++ 프로젝트를 시작할 때
--------------------------
그 폴더에서 Claude Code 를 켜고  /개발설정 프로젝트  를 입력하면 그 폴더에도 C++ 초기 설정
(.claude 설정, 빌드·시험 명령이 든 CLAUDE.md, .clangd, .clang-format, .clang-tidy)을 만들어 줍니다.
이미 있는 파일은 건드리지 않습니다.
