# Claude Code로 개발하기 — 쉬운 안내

개발자가 아니어도 됩니다. **하고 싶은 것을 말하면** Claude 가 고치고, 검증하고, 결과를 쉬운 말로 알려 줍니다. 이 문서는 처음 세팅과 매일 쓰는 순서만 담았습니다. 설정이 왜 그렇게 되어 있는지는 [claude-code-settings.md](claude-code-settings.md)에 있습니다.

## 1. 처음 한 번 (새 PC)

1. **필요한 프로그램**: Git for Windows, Node.js 22 LTS. (빌드용 OSGeo4W·Visual Studio·CMake는 [other-pc-setup.md](other-pc-setup.md) 순서대로 이미 있다면 그대로 씁니다.)
2. **Claude Code 설치**: PowerShell 에 한 줄 — `irm https://claude.ai/install.ps1 | iex` (또는 `winget install Anthropic.ClaudeCode`). 처음 실행하면 브라우저에서 로그인하라고 나옵니다.
3. **저장소 안에서 `scripts\setup-claude-dev.bat` 더블클릭.** 자동으로 전역 개발설정, 구조도 도구(Archify), 정의 검색 도구(Graft)를 설치하고 바탕화면에 **Claude 개발 (ka-hgis)** 아이콘을 만듭니다. 이미 있는 것은 건너뛰니 여러 번 눌러도 됩니다.
4. 끝에 나오는 점검 표에서 `[X]`가 남았으면 위에서부터 안내대로 처리합니다(Claude 에게 `/ka-doctor`를 시켜도 됩니다).

## 2. 매일 시작

바탕화면 **Claude 개발 (ka-hgis)** 아이콘 → 검은 창에서 Claude 가 뜹니다. 이 아이콘은 빌드에 필요한 환경을 먼저 준비하고 Claude 를 켭니다. 일반 PowerShell 에서 `claude`만 치면 빌드 환경이 빠져 있을 수 있습니다.

**이 폴더를 믿을까요?** 처음 한 번 이런 창이 뜨면 **예**를 고르세요. 이 저장소의 설정(허용 명령 목록·안전 점검·검증 게이트)은 폴더를 믿기로 해야 적용됩니다. 믿지 않으면 Claude 가 그 설정 일부를 무시하고, 매번 허락을 묻습니다.

## 3. 일하는 순서 (이것만 기억하세요)

| 순서 | 무엇을 | 어떻게 |
|---|---|---|
| 1 | **말한다** | "지도 위 글자가 잘려요"처럼 보이는 증상 그대로. 스크린샷을 붙여도 됩니다. |
| 2 | Claude 가 **고친다** | 짧은 계획을 적고 바로 고칩니다. 큰 변경이라 미리 보고 싶으면 "계획 먼저 보여 줘"라고 하세요. |
| 3 | **검증한다** | `/ka-check` — C++ 를 고쳤다면 필수입니다. 빠뜨리면 Claude 가 끝내기 전에 스스로 알려 줍니다. |
| 4 | **눈으로 확인한다** | `/ka-run` 으로 앱을 열고 Claude 가 알려 준 "확인할 한 가지"만 봅니다. 결과는 "됨" 또는 "안 됨"으로 말해 주세요. |
| 5 | **저장한다** | 마음에 들면 `/ka-save` (git 저장). 원격으로 올리는 푸시는 "푸시까지"라고 따로 말할 때만 합니다. |

## 4. 명령 모음

| 명령 | 하는 일 |
|---|---|
| `/ka-help` | 사용법 안내 |
| `/ka-status` | 지금 어디까지 왔는지 한눈에 |
| `/ka-doctor` | 이 PC에 빠진 도구 점검, 설치 방법 안내 |
| `/ka-work 할 일` | 새 작업을 이해→계획→수정→검증→기록 순서로 진행 |
| `/ka-check` | C++ 수정 후 검증(Graft·clangd·구조도·시험) |
| `/ka-run` | 만든 앱 열기(이미 켜져 있으면 그대로 둠) |
| `/ka-save` | 바꾼 파일만 골라 저장(커밋). 계정 파일이 섞이지 않게 검사 |
| `/ka-undo` | 방금 한 수정이나 저장을 안전하게 되돌리기 |
| `/개발설정` | Claude 개발설정을 전역+프로젝트에 적용·점검(새 C++ 프로젝트 초기 설정에도) |
| `/effort medium` | 더 빠르게(기본은 정확 우선인 `high`) |
| `/rewind` | 이번 대화에서 Claude 가 한 편집을 되돌리기(Claude Code 기본 기능) |

명령을 외우지 않아도 "상태 알려줘", "환경 점검해줘", "저장해줘"처럼 말하면 Claude 가 알아듣습니다(저장·되돌리기·앱 열기·`/개발설정`은 실수 방지를 위해 명령으로만 동작합니다).

## 5. 화면 읽는 법

- **맨 아래 줄**: `Opus 5.5 · 노력 high │ 컨텍스트 ▓▓░░ 32% │ 브랜치 … │ ⚠ C++ 수정 3개 검증 대기`. 컨텍스트가 80%를 넘으면 `/compact` 또는 새 대화(`/clear`)를 권합니다. `⚠ … 검증 대기`가 보이면 `/ka-check`를 하기 전에는 "완료"가 아닙니다.
- **권한 창**("허용할까요?")이 뜨면 Claude 가 쉬운 말로 무엇을 하려는지 먼저 설명합니다. 설명이 이해되면 "예", 모르겠으면 "아니오" 후 이유를 물어보세요. 파일 수정은 기본으로 자동 허용이고, 명령 실행·저장·푸시는 묻습니다.
- **계획 모드**: `Shift+Tab`으로 "계획만 세우고 수정 안 함" 모드로 바꿀 수 있습니다. 신중히 가고 싶을 때 쓰세요.
- **"검증 게이트" 메시지**: Claude 가 C++ 를 고쳤는데 확인 기록이 없다며 스스로 이어서 실행하는 것입니다. 오류가 아닙니다. 두 번까지 되돌려 보내고, 그래도 못 하면 "검증 미완료"라고 알려 줍니다.
- **"차단됨"/"hook error" 메시지**: 위험한 명령(강제 푸시, 통째 삭제, 실행 중인 앱 종료 등)을 안전 점검이 막은 것입니다. Claude 가 다른 방법을 찾습니다. 정말 필요한 작업이면 Claude 에게 이유를 말해 주세요.
- **Graft 서버 "failed"**(`/mcp`에서 보임): Graft 엔진이 설치되지 않은 것입니다. `scripts\setup-claude-dev.bat`을 실행하세요. 그 사이에도 다른 기능은 동작하고, 없는 도구는 "검증 미완료"로 보고됩니다.

## 6. 안전 규칙 (Claude 도 지킵니다)

- 저장(커밋)·푸시는 **말해야만** 합니다. 강제 푸시, `reset --hard`, 히스토리 재작성은 하지 않습니다.
- 계정·키 파일(`config\*.ini`, `.env` 등)은 커밋하지 않습니다. `/ka-save`가 저장 전에 비밀 검사를 합니다.
- 실행 중인 고고학 전용 HGIS 앱은 요청 없이 끄거나 다시 열지 않습니다. 조사 원본(`.gpkg`)은 저장·내보내기·편집 요청이 아니면 건드리지 않습니다.
- 포터블 만들기·바탕화면 복사는 "포터블 만들어 줘"라고 할 때만 합니다.
- 빌드·시험이 안 되는 환경(클라우드 등)에서는 통과했다고 말하지 않고 "Windows PC에서 확인 필요"라고 합니다.

## 7. 새 C++ 프로젝트를 시작할 때

새 폴더에서 Claude 를 켜고 `/개발설정 프로젝트`. 그 폴더에 Claude 설정, 규칙, `CLAUDE.md`(빌드·시험 명령을 자동 감지), `.clangd`·`.clang-format`·`.clang-tidy`, `.gitignore` 블록이 만들어집니다. 이미 있는 파일은 건드리지 않고, 만들기 전에 `/개발설정 점검`으로 무엇이 바뀔지 미리 볼 수 있습니다. 전역 설정은 이미 적용되어 있으니 모든 프로젝트에서 같은 방식(한국어·결론부터·검증 우선)으로 일합니다.

## 8. 막혔을 때

1. `/ka-doctor` — 빠진 도구와 해결 방법.
2. `/ka-status` — 지금 상태와 다음에 할 일.
3. `/ka-help` — 이 문서의 요약.
4. 그래도 안 되면 화면을 그대로 캡처해서 Claude 에게 보여 주세요. 오류 영어를 읽을 필요는 없습니다.

## 옛 개발 도구 정리 상태

이 저장소는 예전에 Cursor·Codex·Grok·OpenCode 등을 거쳐 왔고 이제 Claude Code 하나입니다. `.cursor/`, 옛 예약 작업 스크립트 등은 정리되었거나 정리 예정입니다. 30분마다 원격으로 강제 푸시하던 옛 자동 백업(`ka-hgis-auto-git-push` 예약 작업)이 이 PC에 남아 있다면 `setup-claude-dev.bat`이 알려 주고 지울지 묻습니다(묻지 않고 지우지 않습니다).
